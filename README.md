# Sriya Thotakura — earlier portfolio site (archived)

This is an earlier version of my portfolio website (React, Vite, matter-js), kept for the record. The current site is **[sriyathotakura.com](https://sriyathotakura.com)**, and the current project repositories are listed in **[portfolio-projects](https://github.com/SriyaThotakura/portfolio-projects)**.

The site was built on [Suraj Thotakura's open-source portfolio template](https://github.com/SurajThotakura/surajthotakura-blog), which is released under CC0 1.0 (see `LICENSE.md`). The page content and project material are mine.

## Running locally

```bash
pnpm install
pnpm dev     # development server
pnpm build   # static build in dist/
```
